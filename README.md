# Sprint_6

## Проект по автоматизации тестирования сервиса "Яндекс.Самокат" с использованием Selenium, Pytest и Allure.

### Стек:
- Python
- Pytest
- Selenium WebDriver
- Allure

## Что проверяется:
### test_main_page.py
Проверка блока FAQ на главной странице:

раскрытие вопросов;
проверка текста ответов.

### test_order_page.py
Проверка позитивного сценария оформления заказа:

через верхнюю кнопку «Заказать»;
через нижнюю кнопку «Заказать».

### test_redirect.py
Проверка переходов по логотипам:

переход на главную страницу по логотипу Самоката;
переход на страницу Дзена по логотипу Яндекса.

## Установка зависимостей
Перед запуском тестов установить зависимости:

При наличии версии Python от 3+ - pip3 install -r requirements.txt
При версии ниже - просто убрать 3 после pip

## Запуск тестов
Запуск всех тестов:
pytest -v

## Генерация результатов Allure
Для запуска тестов с сохранением результатов Allure:
pytest -v --alluredir=allure_results

Быстрый просмотр:
allure serve allure_results
